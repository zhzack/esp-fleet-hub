## 1. 业务背景与系统愿景

### 1.1 业务背景与行业痛点
在传统的远程服务器管理、多设备集群操作、机房运维以及跨系统协同办公场景中，传统的远程控制软件（如 TeamViewer、AnyDesk、RDP、VNC）存在以下核心局限：
1. **强依赖目标操作系统与客户端软件**：必须在受控机上预先安装 Agent 或后台守护进程，对于锁屏、BIOS 阶段、无公网网络、受限权限操作系统或严密合规环境无法使用。
2. **操作系统兼容壁垒**：Windows、macOS 与 Linux 的快捷键与修饰键逻辑差异巨大（例如 Win 键 vs Cmd 键），跨平台键盘映射常导致误操作。
3. **软硬件延迟高**：视频编码与软件输入捕获引入 50~150ms 延迟，快速连点、甩动鼠标或拖拽手势容易掉帧卡顿。

### 1.2 系统愿景与定位
**HID Gateway Platform** 致力于构建一个**完全免驱、物理级硬件模拟、高吞吐、超低延迟的局域网外设控制与中继平台**。
受控电脑（Mac / PC / 服务器）仅需将 ESP32-S3 视作一个标准的 USB 复合键盘鼠标或蓝牙 5.0 BLE 外设，**无需在受控机安装任何驱动或软件**。操作员可通过现代 Web 控制台、移动端触控板或直接将控制端真实键鼠直通给目标机，实现真正的“硬件级零入侵”遥控。

## 3. 功能需求规格清单 (Functional Requirements)

### 3.1 设备连接与硬件抽象管理 (FR-DEV)

| 编号 | 功能需求 | 详细说明与验收准则 | 优先级 |
|---|---|---|---|
| **FR-DEV-001** | 设备唯一身份识别 | ESP32 硬件出厂或首次初始化生成唯一 UUID（NVS 持久化），服务端基于 UUID 识别与建档。 | P0 |
| **FR-DEV-002** | 双向 WebSocket 长连接 | ESP32 开机联网后主动连入服务端 `/ws/device`，保持长连接与毫秒级双向事件调度。 | P0 |
| **FR-DEV-003** | 动态心跳与存活检测 | 设备端每 30 秒上报一次心跳帧（包含运行时间、自由内存、BLE连接数）；服务端动态维护在线状态。 | P0 |
| **FR-DEV-004** | 设备安全挑战鉴权 | 服务端配置共享密钥时，设备连入触发 HMAC-SHA256 挑战-应答，校验合法后方可完成注册。 | P0 |
| **FR-DEV-005** | 传输模式动态切换 | 支持 `auto` / `usb` / `ble` 三种模式。切换写入 NVS 持久化存储，设备重启或 OTA 升级后不丢失。 | P0 |
| **FR-DEV-006** | 局域网 WiFi 自动恢复 | 存储已知 WiFi 列表，网络中断后自动降级重连，支持配网 AP 恢复模式。 | P1 |

### 3.2 物理 HID 输出能力 (FR-HID)

| 编号 | 功能需求 | 详细说明与验收准则 | 优先级 |
|---|---|---|---|
| **FR-HID-001** | USB HID 复合设备 | 模拟标准 USB 复合键盘与鼠标，支持 1000Hz 轮询率（bInterval=1ms），即插即用免驱识别。 | P0 |
| **FR-HID-002** | BLE HID 蓝牙广播与配对 | 采用 NimBLE 协议栈，遵循标准 HOGP 规范。HID 特征及 CCCD 强制加密配对，LTK 存储至 NVS。 | P0 |
| **FR-HID-003** | BLE 多主机并发连接 | 固件支持最多 3 台主机同时建立 BLE 连接；连接未满时保持广播，多台在线时默认采用镜像广播。 | P0 |
| **FR-HID-004** | 鼠标流式高频位移 | 支持连续 `mouse_move` 增量下发；固件端具备缓冲累加机制与端点忙补发，防丢位移与超界截断。 | P0 |
| **FR-HID-005** | 真实按键状态机与防丢点击 | 支持 `mouse_down` / `mouse_up` 原语，具备 `s_buttons_dirty` 脏标记重试机制，杜绝拖拽中断或点击丢失。 | P0 |
| **FR-HID-006** | 全键盘键位与修饰键透传 | 支持标准 104 键、F1-F12、功能键、媒体键，支持 Ctrl/Shift/Alt/Meta 多修饰键位掩码任意组合。 | P0 |

### 3.3 调度、协议与控制中心 (FR-SCHED)

| 编号 | 功能需求 | 详细说明与验收准则 | 优先级 |
|---|---|---|---|
| **FR-SCHED-001** | V2 统一消息信封 | 所有请求与响应遵循 `WsEnvelope`（包含 `header`, `routing`, `payload`），支持单播、组播与多目标派发。 | P0 |
| **FR-SCHED-002** | 异步精准 ACK 追踪 | 动作下发支持 `need_ack` 标志，设备端执行完毕后返回硬件 ACK（带真实耗时与错误码），超时返回 E002。 | P0 |
| **FR-SCHED-003** | 硬件错误真实透传 | 当硬件明确报错（如蓝牙未连接 E007）时，调度器立即终止网络重试并上报错误，杜绝假成功 ACK。 | P0 |
| **FR-SCHED-004** | 多设备并发调度 | 前端选择多台目标设备时，后端通过 `asyncio.gather` 并发派发，并在前端逐台聚合回显状态与延迟。 | P1 |
| **FR-SCHED-005** | 目标主机平台感知 | 支持用户对受控机地址打标（Win / Mac / Linux），控制台自动自适应切换快捷键（如 Cmd+Tab vs Alt+Tab）。 | P1 |
| **FR-SCHED-006** | 真实键鼠接管 (Takeover) | 浏览器利用 Pointer Lock API 捕获控制端物理鼠标原始运动增量与真实按键，1000Hz 1:1 直通目标机。 | P1 |
| **FR-SCHED-007** | 跨平台自动化宏流水线 | 宏编辑器支持拖拽编排按键、鼠标、延时与文本，针对 Win/Mac/Linux 配置独立步骤分支并自适应执行。 | P1 |

### 3.4 固件升级与安全可靠性 (FR-OTA)

| 编号 | 功能需求 | 详细说明与验收准则 | 优先级 |
|---|---|---|---|
| **FR-OTA-001** | 双备份应用程序槽 | Flash 划分 `otadata`, `ota_0`, `ota_1` 分区，支持交替在线写入，防止单分区损坏变砖。 | P0 |
| **FR-OTA-002** | SHA-256 下载流校验 | 固件升级下载过程中使用 mbedtls 进行流式哈希累加比对，校验失败绝不切换启动槽位。 | P0 |
| **FR-OTA-003** | 90s 健康自检与自动回滚 | 新固件重启后进入 `PENDING_VERIFY` 阶段，90s 内未能成功注册 WS 服务端则自动回滚旧分区重启。 | P0 |
| **FR-OTA-004** | Web 端一键固件推送 | 管理员可在前端固件中心拖拽上传 `.bin` 文件，一键多选在线设备批量推送并展示环形进度条。 | P1 |

## 4. 非功能性需求与性能指标 (NFR)

### 4.1 延迟与吞吐性能指标
- **控制链路整体延迟**：
  - Web 控制端 $\rightarrow$ 后端网关 $\rightarrow$ ESP32 硬件 $\rightarrow$ USB 目标机：平均延迟 $\le 5\text{ms}$，P99 延迟 $\le 10\text{ms}$。
  - Web 控制端 $\rightarrow$ 后端网关 $\rightarrow$ ESP32 硬件 $\rightarrow$ BLE 蓝牙目标机：平均延迟 $\le 20\text{ms}$，P99 延迟 $\le 35\text{ms}$（受蓝牙 15ms 连接间隔限制）。
- **鼠标流式吞吐量**：
  - HTTP / WebSocket 流式透传吞吐量达到 **$600\sim 650\text{ actions/s}$**（单包处理耗时 $\le 1.6\text{ms}$），满足高 DPI 鼠标极速甩动需求。
  - 数据库事务旁路：流式动作不触发同步磁盘落库，主库开启 SQLite WAL 模式，确保微秒级事务提交。

### 4.2 稳定性与可靠性
- **点击防丢率**：在高速移动（100+ 报文/秒）并突发连击场景下，按键丢失率严格为 **0%**。
- **内存防溢出**：ESP32 固件严禁在微小调用栈（如 FreeRTOS 软件定时器任务 3KB 栈）中执行 BLE GATT 通知链，专用排空任务栈深度 $\ge 4\text{KB}$。
- **OTA 防变砖率**：升级失败或固件 Panic 崩溃时，100% 自动回滚回可用旧固件槽位。

### 4.3 兼容性与平台矩阵
- **服务端运行环境**：Linux (Ubuntu 22.04+ / Debian / Docker)、Windows 10/11、macOS。
- **受控主机操作系统**：
  - macOS：macOS 12+，经实测 macOS 27（Grey-2）蓝牙/USB 完全免驱兼容，支持 Cmd 组合键与手势。
  - Windows：Windows 10 / 11 / Server，支持 Win 键、任务视图、安全登录（Ctrl+Alt+Del）。
  - Linux：Ubuntu / Debian / CentOS / fnOS NAS，支持标准 X11 / Wayland 外设输入。
- **控制端浏览器**：Chrome 90+、Edge 90+、Safari 15+、Firefox 90+（支持 WebSocket 与 Pointer Lock API）。

## 5. 硬件与固件规格约束

- **主控芯片**：Espressif ESP32-S3-WROOM-1 (或兼容模组)
- **片上内存**：8MB Octal PSRAM + 16MB Quad SPI Flash
- **无线协议**：2.4GHz Wi-Fi (802.11 b/g/n) + Bluetooth 5.0 (BLE)
- **外设接口**：
  - USB 0 (原生 OTG / Type-C)：配置为 TinyUSB 复合设备（键盘 + 鼠标）
  - UART 0 (CH343 USB-TTL，COM 口)：波特率 115200 (日志/CLI)，921600 (线刷)
- **软件开发套件 (SDK)**：ESP-IDF v5.4.1 (NimBLE 协议栈 + TinyUSB 堆栈)
- **分区表规划**：
  - `nvs`：32KB (配置与密钥持久化)
  - `otadata`：8KB (引导状态槽位记录)
  - `ota_0`：1800KB (固件分区 0)
  - `ota_1`：1800KB (固件分区 1)
  - `storage`：其余空间留作文件存储
